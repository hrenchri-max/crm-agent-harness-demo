CRM agent harness

One flow, end to end. A sales rep asks the agent to follow up on stalled deals. Every tool runs as the rep, every write waits for the rep's approval policy, and every step lands in an append-only event log.

The model's steps on this page were written ahead of time in the exact format the Claude API returns. Everything else (the state machine, permission checks, approval gate, retries, audit log and crash recovery) runs live in your browser. npm run live runs the same harness against the real API with your own key.
